# Mini App «Проверка пакета» — сверка смет, актов и договоров в Telegram

## Почему Mini App, а не только бот
Бот через Bot API скачивает файлы только до **20 МБ**, а реальные пакеты ИД — сканы по 70–110 МБ.
Mini App — веб-страница внутри Telegram: файлы уходят **напрямую на наш сервер по HTTPS**, лимит задаём сами
(по умолчанию 500 МБ на пакет). Бот остаётся входом (кнопка меню) и присылает уведомление, когда отчёт готов.

```
Telegram ─ бот (aiogram) ── кнопка «Проверка» ─┐
                                              ▼
           Mini App (webapp/index.html) ── HTTPS ──► FastAPI (app/main.py)
                                                       │  проверка подписи initData
                                                       ▼
                                       service.py: файлы на диск, очередь (2 потока)
                                                       ▼
                                  smeta_check.pipeline: классификация → проверки → report.xlsx
                                                       ▼
                                  sendMessage «Проверка готова» + кнопка «Открыть отчёт»
```

## Что внутри
| Путь | Что делает |
|---|---|
| `webapp/index.html` | Интерфейс: загрузка с прогрессом, штамп-сводка (ячейки = фильтр), замечания, план АОСР, скачивание Excel. Тема Telegram светлая/тёмная. |
| `app/tg_auth.py` | Проверка подписи initData (без неё любой прочтёт чужие отчёты) и подписанные ссылки на скачивание. |
| `app/service.py` | Задания: потоковая запись файлов с лимитом, фон, статус, изоляция пользователей, автоудаление через 30 дней. |
| `app/main.py` | API: `GET /`, `GET/POST /api/jobs`, `GET /api/jobs/{id}`, `GET /api/jobs/{id}/report?t=…` |
| `bot/bot.py` | `/start` с кнопкой, кнопка меню, ответ на файлы, присланные в чат. |
| `smeta_check/` | Проверки (ЛСР↔КС-2, договор↔ЛСР↔ВОР↔ТЗ, нормы материалов) + `pipeline.py` — автоопределение файлов. |

## Посмотреть интерфейс прямо сейчас
Откройте `webapp/index.html` двойным щелчком — включится демо на обезличенных данных реальной проверки.

## Локальный запуск
```bash
python -m venv venv && source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt                       # + poppler-utils (pdftotext) в системе
python -m unittest -v tests.test_core tests.test_api  # подпись, безопасность, полный цикл
DEV_MODE=1 uvicorn app.main:app --reload              # http://127.0.0.1:8000/?demo=1 — демо
```
`DEV_MODE=1` пускает API без Telegram — **только на своём компьютере**.

## Боевой запуск
1. **Бот.** @BotFather → `/newbot` → токен в `.env`. Там же: Bot Settings → Menu Button → URL Mini App
   (бот ставит кнопку и сам при старте).
2. **Сервер в РФ** (Selectel, Yandex Cloud, Timeweb и т.п.). В ИД есть ФИО и должности ответственных —
   это персональные данные, по 152-ФЗ их хранение должно быть в РФ. Сметы клиентов — коммерческая тайна.
3. **Домен + HTTPS** обязателен (Telegram открывает Mini App только по https). Проще всего Caddy:
   `deploy/Caddyfile`. Если ставите nginx — `client_max_body_size 500m;` и `proxy_read_timeout 600s;`,
   иначе большие пакеты оборвутся на 1 МБ.
4. **Код и окружение:** `/srv/miniapp`, `cp .env.example .env`, venv, `pip install -r requirements.txt`,
   `apt install poppler-utils`.
5. **Сервисы:** `deploy/miniapp-web.service`, `deploy/miniapp-bot.service` → `/etc/systemd/system/`,
   `systemctl enable --now miniapp-web miniapp-bot`.
6. **Проверка:** открыть бота → «Проверка» → загрузить ЛСР + КС-2.

## Ограничения MVP (честно)
- Сканы без текстового слоя не распознаются (нужен OCR) — пользователь видит «Уточнить», а не молчание.
- АОСР/журналы пока не проверяются — это модуль верификатора ИД, его подключить в `pipeline.py` следующим.
- Хранение на диске в JSON. Организации, роли (Owner/Admin/ПТО/Engineer/Viewer), общий доступ к проверкам —
  после переноса в PostgreSQL.
- Загрузка одним запросом: обрыв мобильной связи на 100 МБ = повторная отправка. Докачку (по частям) —
  когда появятся жалобы.
- Если позже в проверки добавится LLM: провайдер должен быть доступен с сервера в РФ — заложить заранее.
